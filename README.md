# 🩺 Historial Clínico - Backend

Microservicio en Node.js + Express + TypeORM para gestionar historiales clínicos por usuario autenticado.

---

## 🚀 Tecnologías

- Node.js
- Express
- TypeScript
- PostgreSQL
- TypeORM
- JWT (autenticación)
- Bcrypt (seguridad)
- Class-validator (validaciones)

---

## ⚙️ Requisitos

- Node.js >= 18
- PostgreSQL
- Git

---

## 🧪 Instalación

```bash
git clone https://github.com/TU_USUARIO/Historial-Clinico.git
cd Historial-Clinico
npm install
cp .env.example .env
